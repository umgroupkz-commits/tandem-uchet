Памятки по ролям

Тандем KZ · что делать каждый день и где это в программе. Выберите свою роль.
Главное правило: всё, что пришло, ушло или испортилось, заносится в тот же день. Остаток в программе верен ровно настолько, насколько занесены документы.

Каждый день

Принять товар от поставщика

Склад с телефона → Приёмка
  1. Поставщик — начните вводить название и выберите из списка.
  2. Номер и дата накладной — как на бумаге.
  3. Позиции: количество и цена из накладной. Частые позиции склада предложены сверху.
  4. «Провести».

Цена из прихода становится учётной ценой сырья — от неё считается себестоимость блюд. Ошибка в цене здесь даёт неверный фудкост везде.

Передать на другой склад

Склад с телефона → Перемещение

Выберите склад-получатель, позиции и количество. Если программа предупреждает «уйдёт в минус» — скорее всего, не занесён приход: сначала занесите его.

Списать порчу, проработку, питание персонала

Склад с телефона → Списание

Причина обязательна. Одним словом в комментарии — что случилось: «истёк срок», «разбили при разгрузке».

По графику

Инвентаризация

Склад с телефона → Инвентаризация

Пересчёт «вслепую»: программа не показывает, сколько должно быть, — вводите то, что насчитали. Перед проведением увидите расхождения и подтвердите их. Позицию, которой нет в списке, добавьте поиском.

После проведённой инвентаризации документы с более ранней датой по этому складу не меняются — занесите всё до пересчёта.

Если что-то не так

  • Нет связи — черновик остаётся на телефоне, откройте сценарий снова и нажмите «Провести».
  • Провели с ошибкой — отмена и исправление в бэк-офисе: Склад → Документы → открыть → «Отменить проведение».
  • Нет нужного склада в списке — склады закрепляет администратор в карточке пользователя.
Открыть склад с телефона
Главное правило: техкарта — это то, по чему программа списывает продукты при каждой продаже. Неверная карта = неверный остаток каждый день.

Каждый день

Акт производства полуфабрикатов

Бэк-офис → Склад → «+ Новый документ…» → Производство

Склад кухни, что выпустили и сколько. Программа спишет сырьё по карте и поставит полуфабрикат на остаток по себестоимости. Перед проведением видно, что будет списано.

Продажа блюда списывает его ингредиенты на один уровень: если в карте блюда стоит полуфабрикат, спишется полуфабрикат — поэтому его выпуск нужно заносить актом.

Когда меняется рецептура

Новая версия карты, а не правка старой

Бэк-офис → Техкарты → блюдо → «Новая версия с даты…»

Старая версия закроется датой, новая начнёт действовать с выбранного дня. Продажи прошлых дней останутся посчитанными по старой карте.

Раз в неделю

Вкладка «Готовность»

Бэк-офис → Склад → Готовность
  • «Сырьё без цены» — из-за него не считается себестоимость; сверху те, что стоят в наибольшем числе карт.
  • «Блюда на продаже без техкарты» — при продаже спишутся «как есть». Заведите карту.

Фудкост меню

Бэк-офис → Техкарты → «Фудкост меню»

Красным — блюда выше порога. Причина обычно одна из трёх: подорожало сырьё, занижена цена продажи, в карте завышено брутто.

Открыть бэк-офис
Главное правило: приход в программе должен совпадать с бумажной накладной — номер, дата, цены. По нему будут считаться долги поставщикам.

Каждый день

Проверить приходы за день

Бэк-офис → Склад → Документы → тип «Приход»

Откройте каждый приход кладовщика, сверьте с накладной. Ошибка в цене: «Отменить проведение» → исправить → «Провести».

Проверить продажи точек

Бэк-офис → Склад → Продажи

У каждого отчёта точки должно стоять «проведена». Если «не проведена» или «устарела» — нажмите «Провести продажи за период». «Нет склада» — точке не привязан склад (раздел «Склады»).

Раз в месяц

Оборотная ведомость

Бэк-офис → Склад → Ведомость

Остаток на начало, приход, продажи, списания, инвентаризация, остаток на конец — по складу за период. Выгружается в CSV. Устроена как «Расширенная оборотно-сальдовая ведомость» iiko — по ней сверяются обе системы.

Контрагенты

Бэк-офис → Контрагенты

Нового поставщика заведите до первой приёмки — кладовщик выбирает только из справочника. Поиск понимает часть БИН и телефон.

Открыть бэк-офис
Три экрана отвечают на три вопроса: сколько заработали, сколько это стоило, что лежит на складах.

Каждый день — 5 минут

Сколько заработали и сколько это стоило

Бэк-офис → Склад → Продажи

Итоги за период: выручка, себестоимость, валовая прибыль и фудкост по каждой точке, ниже — по позициям. Фудкост выше 35 % выделен красным.

Кто не сдал отчёт, сверка с выписками

Главная страница → вход по коду собственника

Сводка по точкам: выручка по каналам, расхождения кассы, расходы без чека.

Раз в неделю

Что лежит на складах и на сколько денег

Бэк-офис → Склад → Остатки

Остаток и средняя цена по каждому складу, сумма внизу. Минус — признак незанесённого прихода или производства.

Что мешает учёту

Бэк-офис → Склад → Готовность

Одна страница проблем: сырьё без цены, блюда без техкарт, точки без склада, непроведённые продажи. Цель — «чисто» по красным пунктам.

Где теряем

Бэк-офис → Склад → Документы → тип «Инвентаризация»

В проведённой инвентаризации видны расчёт, факт, разница и сумма недостачи по каждой позиции.

Открыть бэк-офисСводка по точкам
Главное правило: отчёт сдаётся в конце каждой смены. Проданное в отчёте сразу списывает продукты со склада точки.

В конце смены

Дневной отчёт

Главная страница → точка и её код
  1. Выручка по каналам: наличные, Kaspi QR, переводы.
  2. Продажи по позициям — найдите поиском, количество кнопками «+» и «−».
  3. Расходы из кассы — только с номером чека.
  4. «Сохранить отчёт».

Ошиблись — откройте тот же день, исправьте и сохраните снова: склад пересчитается сам. После инвентаризации склада отчёты прошлых дней склад уже не меняют — исправление увидит бухгалтер.

Открыть отчёт точки
Главное правило: каждая продажа пробивается сразу, в момент продажи. Чек тут же попадает в отчёт дня и списывает продукты со склада точки.

В течение дня

Пробить продажу

Касса → точка, её код и ваша фамилия
  1. Нажмите на позицию — она появится в чеке. Нет на экране — найдите поиском или выберите группу.
  2. Количество — кнопками «+» и «−» или впишите число (для весового — килограммы: 0,35).
  3. Продаёте со скидкой — нажмите на цену в строке чека и впишите свою.
  4. Нажмите способ оплаты: «Наличные», «Kaspi QR», «Перевод» или «Карта». Чек пробит.

Пропала связь — продолжайте работать. Чеки сохраняются на планшете и уйдут сами, когда связь вернётся; вверху видно, сколько ждут отправки.

Ошиблись в чеке

Касса → «Смена»
  1. «Исправить» — чек откроется, поправьте позиции или оплату и нажмите способ оплаты ещё раз.
  2. «Отменить чек» — если продажи не было. Напишите причину: её увидит собственник.

В конце смены

Закрыть смену

Касса → «Смена» → «Закрыть смену»
  1. Сверьте итоги по наличным, Kaspi QR, переводам и карте с ящиком и терминалом.
  2. Впишите остаток на начало, сданное и пересчитанные наличные.
  3. Расходы из кассы — только с номером чека.
  4. «Закрыть смену».

Суммы выручки на этой странице не правятся — они собраны из чеков. Нашли ошибку — исправьте чек в кассе и закройте смену заново.
