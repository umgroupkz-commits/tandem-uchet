# Подпроект «Ядро»: отложенные замечания ревью

Дата: 5 сентября 2026. Все задачи плана `2026-09-04-uchet-core.md` выполнены, финальное
ревью ветки пройдено, слито в `main`. Ниже — то, что ревью отметило как «мелочь» или
«потом»: не блокирует работу, но должно быть учтено в подпроектах 2–6.

## Безопасность входа (закрыть до передачи бэк-офиса за пределы Светланы и Андрея)

- Ветка блокировки (`tandem_office`, `login`) отвечает раньше `crypt` и другим текстом —
  подтверждает существование логина и даёт держать чужой логин заблокированным
  5 запросами в 15 минут. Лечится единым ответом и задержкой; сейчас пользователей два.
- PIN 4+ цифр, лок 5 попыток / 15 минут — достаточно для внутреннего инструмента, не для
  публичного.
- Временный PIN при создании пользователя вводится через `window.prompt` открытым текстом.
- `change_pin` и смена роли не обрывают другие сессии пользователя.

## Перенос и синхронизация с iiko

- `tandem_sync_items` (старый скрипт `tools/iiko-sync-items.mjs`) при обновлении ставит
  `source='iiko_api'` и тем снимает защиту правок бэк-офиса; `group_id` подбирается по имени
  группы с `limit 1` без порядка; позиции с пустой категорией остаются без группы.
  Решение на подпроект 2: либо убрать скрипт как замещённый переносом, либо привести к
  правилам `tandem_migrate`. **Не закрыто** — `tandem_sync_items`/`iiko-sync-items.mjs`
  остались как есть; решить в подпроекте 3.
- **Закрыто в подпроекте «Техкарты» (миграция 0014):** аналогичная пара для карт —
  `tandem.item_chart` и RPC `public.tandem_sync_charts` — удалена, скрипт
  `tools/iiko-sync-charts.mjs` снесён (`git rm`); заменены переносом
  (`tools/iiko-migrate-charts.mjs`, виды `charts`/`costs`).
- `item_save` помечает `source='office'` при любой правке (даже деактивации) — после этого
  перенос строку не обновляет; интерфейс об этом не предупреждает.
- `tandem_migrate`: если одна входная строка совпадает по `iiko_id` с одной записью и по коду
  с другой, вся пачка вернёт `validation` без указания строки.
- `iiko-migrate.mjs` берёт склады/контрагентов по первой организации (`orgs[0]`).
- **Перед подпроектом 4:** `raw_usage` в `tandem_api` (экран точки, «расход сырья») берёт
  действующую на сегодня техкарту, а не карту на дату отчёта. Пока карты почти не менялись,
  разницы не видно; как только у блюда появится вторая версия, расход сырья за прошлый период
  посчитается по новой карте. Лечится передачей даты отчёта в `tandem.active_chart`.

## RPC и данные

- Неверный формат поля ловится (`invalid_text_representation`), но нарушение внешнего ключа
  (`group_id` на несуществующую группу) по-прежнему уходит сырым 500.
- `items_search`/`counteragents_list`: `%` и `_` в запросе не экранируются для ILIKE; поиск
  по БИН — только точное равенство, по телефону нет.
- `item_save`: цену по умолчанию нельзя очистить (coalesce).
- ~~`unit_id` допускает null в схеме — перед документами склада сделать `not null`~~ —
  **закрыто в подпроекте «Техкарты» (миграция 0010):** `items.unit_id` теперь `not null`.
- `group_save` не проверяет цикл `parent_id`; дерево строится от корня, циклические группы
  просто исчезнут из него.
- Нет `updated_at`/`updated_by` на новых таблицах — для документов понадобится журнал,
  проще заложить общий приём в подпроекте 3.
- `sessions` без индекса по `user_id`; чистка только при входе.
- Миграции 0001 (`update item_type` без `where`) и обёртки прав в 0003–0005: история
  миграций Supabase отличается от файлов только DO-обёрткой; поведение то же.

## Фронт

- Версия сборки не «одна константа»: `?v=1` в импортах, `office.html` и `BUILD` в `api.js`.
- Новая позиция получает таблицу цен по точкам только со второго открытия карточки.
- В карточках складов/контрагентов нет фокуса на первом поле; в `app.js` неиспользуемая
  переменная `current`.

## Тест

- `office-smoke.mjs`: `call()` без `try/catch` (обрыв сети валит скрипт — приемлемо);
  нет постоянного теста на дубль `id` по insert-пути для `stores`/`counteragents`.
- `tandem_sync_items` после правок 0008 не проверялся запуском (скрипт пишет в боевую базу).
- `office.html` под правилом «сначала смените PIN» проверен по коду, не в браузере.

## Что не вошло в репозиторий сознательно

- Базовая схема до 0001 (таблицы точек, `tandem_api`) существует только в Supabase; путь
  переезда — `pg_dump` схемы `tandem`, файлы `db/migrations` — дельта (см. README там).
