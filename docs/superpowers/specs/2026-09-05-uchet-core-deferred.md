  своё окно со скрытым полем. При создании пользователя PIN и раньше вводился в поле типа password.

  (миграция 0015):** `tandem.documents` получила `updated_at`/`updated_by`; у остальных

  `stock_rebuild` из бэк-офиса станет долгим общим пересчётом там, где нужна сверка одного
  участка.
