# Интерактивная обучалка: формат уроков

Движок — `js/tour.js` (обычный скрипт, подключён на всех рабочих страницах). Страница обучения — `test.html`:
человек вводит код обучения (получает все учебные логины и коды), выбирает роль и запускает уроки. Урок идёт
прямо в рабочих экранах: движок затемняет экран вокруг нужного элемента, обводит его, показывает карточку с
объяснением и ждёт, пока человек нажмёт или введёт. Уроки роли лежат в `js/tours/<роль>.js`:
`sklad`, `buh`, `tech`, `kassa`, `point`, `owner`.

```js
TandemTour.register({
  id: "sklad.invoice",            // уникальный, «роль.урок»
  role: "sklad",
  title: "Приходная накладная",   // как в списке уроков
  minutes: 5,                     // сколько примерно идёт
  about: "Как в iiko «Приходная накладная»: …",   // одна-две строки для списка уроков
  page: "office.html",            // страница, где урок начинается (шаги могут менять её через page)
  reset: ["tandem_office", "tandem_office_section"],  // ключи localStorage, которые стереть перед началом
  keep: ["tandem_login"],        // ключи, которые вернуть как были после урока (вход точки на рабочем телефоне);
                                  // ключи из reset возвращаются так же
  steps: [ /* шаги по порядку */ ],
});
```

## Шаг

| Поле | Что значит |
|---|---|
| `title` | Заголовок карточки — коротко, что делаем («Выберите склад»). |
| `text` | Объяснение простыми словами, 1–3 предложения; можно `<b>`. Связь с iiko — здесь («в iiko это …»). |
| `action` | `click` — нажать на цель; `type` — ввести `value` в поле; `select` — выбрать `value` в списке (засчитывается и в момент выбора, если список сам сбрасывается); `fill` — заполнить несколько полей `fields: [{target, value}]` (вход); `wait` — ждать, пока выполнится `until`; `next` — просто объяснение с кнопкой «Дальше». |
| `target` | Что подсветить (см. ниже). У `next` и `wait` — по желанию. |
| `value` | Что ввести или выбрать. Шаблоны `{{sklad.login}}`, `{{sklad.pin}}`, `{{kassa.point}}`, `{{kassa.pin}}`, `{{point.pin}}`, `{{owner_code}}` берутся из учебных учёток. |
| `label` | Для `select`: как назвать выбор в подсказке, если `value` — служебный код (`invoice_in` → «Приход»). |
| `until` | Условие перехода после действия: цель появилась (`{text:"Проведено", sel:".toast"}`), `{gone: цель}` — исчезла, `{textOnPage: "…"}` — текст есть на экране, `{any: [условия]}`. |
| `page` | Страница этого шага, если не та, что у урока (`stock.html`, `index.html`…). Движок сам предложит «Открыть». |
| `navigates` | `true` у `click`, который уводит на другую страницу (ссылка): шаг засчитывается до ухода. |
| `optional` | Шаг можно пропустить кнопкой. Если его цели нет на экране (нет данных — например, неразобранных замечаний), через 4 с карточка показывает `missing` и предлагает пропустить; автопрогон пропускает сам. `skipAlso: N` — пропустить вместе с ним N следующих шагов (они работают в окне, которое он открывал). |
| `match` | `false` у `type`/`select`: шаг засчитывается по `until`, без сравнения значения (экран отклоняет ввод — например, 2,5 шт). У `click` — засчитывается и без нажатия, когда выполнилось `until` (человек нажал Enter). |
| `value` функцией | `value: () => …` — значение считается в момент шага (сумма по экрану). У полей `fill` — `show`: что показать в подсказке вместо значения. |
| `delay`, `timeout` | Для автопрогона: пауза перед действием (по умолчанию 500 мс) и предел ожидания (20 с). |

## Цель

Строка — CSS-селектор (`"#lbtn"`, `"#q"`). Объект:
- `text` — видимый текст (без регистра, вхождение; `exact: true` — целиком); `sel` — какие теги смотреть
  (по умолчанию кнопки, ссылки, вкладки, строки таблиц, пункты поиска `.sitem`, заголовки);
- `placeholder` — поле с такой подсказкой («Добавить позицию»);
- `near` — поле ввода у подписи с этим текстом («Склад-получатель», «Поставщик»); подпись, где текст стоит с начала слова, берётся первой («Куда», а не «Откуда»);
- `within: "modal"` — искать только в верхнем открытом окне (форма документа); или `within: {css: …}`;
- `nth` — какой по счёту из подходящих (с нуля).

Массив целей — запасные варианты по порядку: подсвечивается первая, что есть на экране
(`[{text: "Ввод остатков", sel: "th"}, {text: "Начало", sel: "th"}]`).

Предпочтительно: постоянные `id` (`#llogin`, `#lpin`, `#lbtn`, `#lpoint`, `#q` …) → текст кнопки → `near`.
Не завязывайтесь на порядок колонок и на случайные классы.

## Правила уроков

1. Каждый урок — одна функция программы от начала до результата, 6–20 шагов. Первый шаг — вход (`fill` +
   `click` по «Войти»), если урок начинается с экрана входа; `reset` выходит из прежней учётки.
2. Работаем только на учебных объектах: «Учебный склад кухни», «Учебный склад точки», «Учебный склад кассы»,
   «Учебная точка», «Учебная касса», позиции и поставщики — настоящие (просто выбираем), свои позиции — с
   пометкой «Учебн…». Справочники (номенклатура, техкарты настоящих блюд, цены, пользователи, склады) учебной
   учётке менять нельзя — сервер откажет: там урок показывает форму и просит нажать «Отмена».
3. Текст — как человеку из iiko: «В iiko это …, здесь — …». Без жаргона. Названия кнопок — дословно как на экране.
4. Значения для ввода — правдоподобные и безопасные: количество 10, цена 500 и т. п.
5. Урок проверяется автопрогоном: `node tools/tour-run.mjs <id урока>` — движок сам проходит все шаги; в конце
   «done». Урок готов, только если автопрогон проходит целиком два раза подряд.
